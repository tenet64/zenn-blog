## 自己紹介

もともと理学療法士として働いていましたが、現在はバックエンドエンジニアとして働いています。

転職前はIT業界とは無縁で、プログラミング経験もほとんどありませんでした。

この記事では、

- なぜ医療職からIT業界を目指したのか
- なぜ独学ではなくプログラミングスクールを利用したのか
- 実際の学習内容や転職活動
- スクールの良かった点・微妙だった点

について、実体験ベースでお話しします。

「理学療法士 エンジニア転職」を考えている方の参考になれば幸いです。

## 理学療法士時代の悩み

理学療法士という仕事自体は好きでした。

患者さんが回復していく姿を見るのはやりがいがありますし、人の役に立てる仕事です。

一方で、働く中でいくつか悩みもありました。

### 将来の収入への不安

医療職は安定している反面、給与の伸び幅は大きくありません。

もちろん職場によりますが、

- 昇給額が小さい
- 役職ポストが限られている
- 副業がしづらい

といった課題を感じていました。

### 体力的な負担

理学療法士は意外と体力仕事です。

長時間立ち仕事をしたり、患者さんの介助を行ったりするため、年齢を重ねたときの働き方も考えるようになりました。

## なぜエンジニアを目指したのか

きっかけはシンプルで、

「自分でサービスを作れる人になりたい」

と思ったことです。

調べていく中で、

- スキルが資産になる
- リモートワークが可能
- 実力次第で収入アップが期待できる
- 学び続ける文化がある

という点に魅力を感じました。

特に医療現場では、

「この作業もっと効率化できるのでは？」

と思う場面が多かったため、自分でシステムを作れるようになりたいという気持ちが強くなりました。

## 独学ではなくスクールを選んだ理由

正直なところ、最初は独学で始めました。

しかし数週間で壁にぶつかりました。

### 独学で困ったこと

- 学習順序が分からない
- エラーが解決できない
- 作ったものへのフィードバックがない
- 転職までの道筋が見えない

特に未経験の場合、

「今の勉強方法で本当に合っているのか」

が分からないことが大きな不安でした。

そこで私はプログラミングスクールの利用を決めました。

## 実際の学習内容

私が学習した内容は主に以下です。

### 基礎学習

- HTML
- CSS
- JavaScript
- Git
- GitHub

### バックエンド学習

- Ruby
- Ruby on Rails
- データベース
- SQL

### 開発実践

- ポートフォリオ制作
- チーム開発
- コードレビュー

特にコードレビューは非常に勉強になりました。

現役エンジニアから

「なぜこの書き方が良いのか」

を教えてもらえる機会は独学では得にくいと思います。

## 転職活動で苦労したこと

未経験エンジニア転職で一番大変だったのは書類選考でした。

思っていた以上に落ちます。

私もかなりの数の企業へ応募しました。

また、

- なぜ医療職から転職するのか
- なぜエンジニアなのか
- なぜその会社なのか

を説明できるようになるまで苦労しました。

技術力だけでなく、転職理由の整理も重要だと感じました。

## 転職できた要因

振り返ると、転職できた理由は次の3つだと思います。

### ① 学習を継続したこと

特別な才能があったわけではありません。

毎日少しずつでも学習を続けたことが大きかったです。

### ② ポートフォリオを作ったこと

学習記録だけではなく、

「実際に作れる」

ことを示せたのは大きな武器でした。

### ③ 面接対策をしたこと

転職活動では、

技術力
＝100%

ではありません。

自分の経験や考えを言語化する力も重要でした。

## スクールの良かった点

利用して良かったと感じた点です。

### 学習ロードマップがある

何を勉強すれば良いか迷わなくなりました。

### 質問できる環境がある

エラー解決のスピードが大きく変わります。

### 転職サポートがある

- 履歴書添削
- 職務経歴書添削
- 模擬面接

などを受けられました。

### 仲間ができる

一人で勉強するよりも継続しやすかったです。

## スクールの微妙だった点

もちろん良いことばかりではありません。

### 費用が高い

数十万円単位の投資になります。

誰にでもおすすめできる金額ではありません。

### 受け身だと成長しない

スクールに入れば転職できるわけではありません。

自分で学ぶ姿勢は必須です。

### 人によっては独学でも十分

- 自走力が高い
- 調べるのが苦にならない
- 周囲に相談できる人がいる

このような人は独学でも十分可能だと思います。

## こんな人にはおすすめ

以下のような方にはスクールが合うと思います。

- 医療職からIT転職したい
- 学習時間は確保できる
- 最短で転職を目指したい
- 質問できる環境が欲しい
- 一人だと挫折しそう

## こんな人にはおすすめしない

逆に次のような方には向かないかもしれません。

- 費用をかけたくない
- 自分で学習計画を立てられる
- 転職する意思が固まっていない
- 学習時間を確保できない

スクールはあくまで手段です。

目的が曖昧なまま入ると、費用対効果が下がると思います。

## まとめ

理学療法士から未経験でバックエンドエンジニアへ転職することは十分可能です。

私自身、

- プログラミング未経験
- IT業界未経験
- 医療職出身

という状態からスタートしました。

転職活動は簡単ではありませんでしたが、学習を継続し、ポートフォリオを作り、行動し続けた結果として転職することができました。
